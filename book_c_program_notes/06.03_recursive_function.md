# Recursion

## Recursive Factorial Execution Flow

```c

#include <stdio.h>

// ==========================================
// 1. The Recursive Function
// ==========================================
int f1(int n) {
    int l;

    // recursion Base Condition
    if (n <= 0) {
        return 1;
    }

    // The recursive call
    l = n * f1(n - 1);
    return l;
}

// ==========================================
// 2. The Invocation
// ==========================================
void main() {
    int a;
    a = f1(3);
    printf("%d", a);                            // Output: 6
}

/*
   FLOW DIAGRAM (The Stack Frame Chain)
   The flow maps exactly how these calls stack in RAM and how the
   returns bubble back up, explicitly pointing out the mathematical factorial
   breakdown (3! -> 3 * 2!, etc.) at the bottom.

   PHASE 1: The Forward Pointings (Pushing to the Stack)
   Each call pauses its current execution and creates a brand-new Stack Frame
   with its own independent 'n' and 'l' variables.

    main()            f1(3)              f1(2)              f1(1)             f1(0)
   +-------+         +-------+          +-------+          +-------+         +-------+
   | a: _  | -f1(3)->| n: 3  |  -f1(2)->| n: 2  |  -f1(1)->| n: 1  | -f1(0)->| n: 0  |
   |       |         | l: _  |          | l: _  |          | l: _  |         |       |
   +-------+         +-------+          +-------+          +-------+         +-------+
                                                                                |
                                                                          (Base Cond)
                                                                                |
   PHASE 2: The Backward Returnings (Popping the Stack)                         |
   Once f1(0) hits the base condition (n <= 0), it returns 1, triggering a      |
   chain reaction of multiplications back down the stack.             |
                                                                                v
   +-------+        +-------+          +-------+          +-------+         +-------+
   | a: 6  |        | n: 3  |          | n: 2  |          | n: 1  |         | n: 0  |
   |       |        | l: 6  |          | l: 2  |          | l: 1  |         |       |
   +-------+ <-ret 6+-------+ <-ret 2--+-------+ <-ret 1--+-------+ <-ret 1-+-------+
                   l = 3*f1(2)        l = 2*f1(1)        l = 1*f1(0)       return 1;
                   l = 3 * 2          l = 2 * 1          l = 1 * 1
                   return 6;          return 2;          return 1;
*/

```

This visualizes exactly why the Stack memory segment (which we mapped out earlier) is so
critical. Without a dynamically expanding Stack, recursion would be physically impossible.
Every forward pointing arrow `f1(n-1)` forces the microcontroller's CPU to allocate a fresh
block of SRAM to hold the new `n` and `l` parameters.

For your MCU firmware, this highlights why embedded engineers generally avoid recursion
entirely in production code. If you attempted to recursively parse a deeply nested JSON string
or traverse a large linked list on an STM32, the forward-pointing arrows would rapidly consume
your available RAM. The Stack would eventually collide with the BSS or Data Segment boundaries,
resulting in a catastrophic Stack Overflow and a hardware hard fault.

## auto storage class with recursion

```c
#include <stdio.h>

void test(int i) {
    printf("%d ", i);                           // Pre-recursive print

    if (i <= 2) {                               // RBC (Recursion Base Condition) check
        test(i + 1);                            // Forward recursive call
    } // (*) This is the return address where execution resumes after the
      //     recursive call finishes.
    printf("%d ", i);                           // Post-recursive print
}

void main() {
    test(1);
}
/*
FLOW DIAGRAM (Call Stack & Output Mapping)

    main()            test(1)              test(2)             test(3)
  +-------+  (1)  +---------------+  (2)  +---------------+  (3)  +-------+
  |       | ----> | i: 1          | ----> | i: 2          | ----> | i: 3  |
  |       |       | [return at *] |       | [return at *] |       |       |
  |       | <---- |               | <---- |               | <---- |       |
  +-------+  (6)  +---------------+  (5)  +---------------+  (4)  +-------+

Final Output String generated on the board:
     1   2   3   3   2   1
     |   |   |   |   |   |
     |   |   +---+<--|---|----- Generated by test(3)
     |   +-----------+<--|----- Generated by test(2)
     +-------------------+<---- Generated by test(1)
*/
```

## static storage class with recursion

```c
// Recursion with 'auto' vs. 'static' Memory

#include <stdio.h>

void demo() {
    auto int i;     // Local Stack memory (unique to each frame)
    static int s;   // Data Segment memory (shared across all frames)

    i = ++s;        // Both increment, but 's' retains its previous value
    printf("%d %d\n", i, s);     // Pre-recursive print

    if (i <= 2) {
        demo();                  // Forward recursive call
    } // * Asterisk marks the return address where paused frames resume

    printf("%d %d\n", i, s);                    // Post-recursive print
}

void main() {
    demo();
    demo();
}

/*
Output:
1 1
2 2
3 3
3 3
2 3
1 3
4 4
4 4

FLOW DIAGRAM (Memory Separation)

Data Segment (Shared)
        s [ ~~0~~, ~~1~~, ~~2~~, ~~3~~, 4 ]

Stack Segment (Independent Frames)
  main()
 +------+       Call 1         Call 1          Call 1
 |      | ----> demo() ------> demo() -------> demo()
 |      |       +------+       +------+        +------+
 |      |       | i: 1 |       | i: 2 |        | i: 3 |
 |      |       |  [*] |       |  [*] |        |      |
 |      | <---- +------+ <---- +------+ <----- +------+
 |      |
 |      |       Call 2
 |      | ----> demo()
 |      |       +------+
 |      |       | i: 4 |
 |      | <---- +------+
 +------+
*/
```

## extern storage class with recursion

```c
// Complex Nested Recursion & Memory Persistence

#include <stdio.h>

// ==========================================
// 1. Shared Global Memory (Data Segment)
// ==========================================
int g;                                          // Global variable: Shared by ALL functions.

// ==========================================
// 2. The Inner Recursive Function (test)
// ==========================================
void test() {
    auto int l;                  // Stack: Unique to each test() frame.
    static int s;                // Data Segment: Shared across all test() frames.

    l = ++s;                     // Both increment.
    ++g;                         // Global increments.

    printf("%d %d %d\n", l, s, g);   // Pre-recursive print.
    if (l <= 2) {
        test();                      // test() calls itself.
    }

    // '@' marks the return address where paused test() frames resume.
    printf("%d %d %d\n", l, s, g);          // Post-recursive print.
}

// ==========================================
// 3. The Outer Recursive Function (demo)
// ==========================================
void demo() {
    auto int al;                                // Stack: Unique to each demo() frame.
    static int as;                              // Data Segment: Shared across all demo() frames.

    al = ++as;                                  // Both increment.
    ++g;                                        // Global increments.

    printf("%d %d %d\n", al, as, g);            // Pre-recursive print.

    test();                                     // demo() calls test() BEFORE recursing itself.

    // '*' marks the return address where demo() resumes after calling test().
    if (al <= 2) {
        demo();                                 // demo() calls itself.
    }

    // '#' marks the return address where paused demo() frames resume.
    printf("%d %d %d\n", al, as, g);        // Post-recursive print.
}

void main() {                                   //
    demo();                                     // The entry point.
}

/*
PHYSICAL MEMORY MAPPING (Hardware Architecture)
+------------------------------------------------------------------+
| DATA SEGMENT (Persistent - Shared across all stack frames)       |
|   g (Global)     : 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8          |
|   as (demo stat) : 1 -> 2 -> 3                                   |
|   s (test stat)  : 1 -> 2 -> 3 -> 4 -> 5                         |
+------------------------------------------------------------------+
| SRAM STACK (Independent - Created and destroyed on every call)   |
|   al (demo auto) : 1 (F1) | 2 (F2) | 3 (F3)                      |
|   l (test auto)  : 1 (F1) | 2 (F2) | 3 (F3) | 4 (F4) | 5 (F5)    |
+------------------------------------------------------------------+

EXECUTION FLOW (Forward Pointings & Backward Returnings)
========================================================================
                     PHASE 1: THE FIRST DESCENT
========================================================================
[main]
  ||
  ==> [demo Frame 1] (al:1 | as:1 | g:1)            --> Prints "1 1 1"
        ||
        ==> [test Frame 1] (l:1 | s:1 | g:2)        --> Prints "1 1 2"
              ||
              ==> [test Frame 2] (l:2 | s:2 | g:3)  --> Prints "2 2 3"
                    ||
                    ==> [test Frame 3] (l:3 | s:3 | g:4)--> Prints "3 3 4"
                        (Base Condition Hit)        --> Prints "3 3 4"
                    <== (Returns to test Frame 2)
                    ||
              <== (Resumes @) Local l:2 | Shared s:3, g:4-> Prints "2 3 4"
              ||
        <== (Resumes @) Local l:1 | Shared s:3, g:4      -> Prints "1 3 4"
        ||
      (demo Frame 1 resumes at *) Condition al<=2 is True. Calls demo().

========================================================================
                     PHASE 2: THE SECOND DESCENT
========================================================================
        ||
        ==> [demo Frame 2] (al:2 | as:2 | g:5)      --> Prints "2 2 5"
              ||
              ==> [test Frame 4] (l:4 | s:4 | g:6)  --> Prints "4 4 6"
                  (Base Condition Hit)              --> Prints "4 4 6"
              <== (Returns to demo Frame 2)
              ||
            (demo Frame 2 resumes at *) Condition al<=2 is True. Calls demo().

========================================================================
                     PHASE 3: THE FINAL UNWINDING
========================================================================
              ||
              ==> [demo Frame 3] (al:3 | as:3 | g:7)--> Prints "3 3 7"
                    ||
                    ==> [test Frame 5] (l:5 | s:5 | g:8)--> Prints "5 5 8"
                        (Base Condition Hit)        --> Prints "5 5 8"
                    <== (Returns to demo Frame 3)
                    ||
                  (demo Frame 3 resumes at *) Condition al<=2 is False.
                  (Resumes #) Local al:3 | Shared as:3, g:8 -> Prints "3 3 8"
              <== (Returns to demo Frame 2)
              ||
        <== (Resumes #) Local al:2 | Shared as:3, g:8       -> Prints "2 3 8"
        ||
  <== (Resumes #) Local al:1 | Shared as:3, g:8             -> Prints "1 3 8"
  ||
[main] (Execution Complete)
*/
```

## main() vs recusion

```c
// Infinite Execution: Loops vs. Recursion

#include <stdio.h>

// ==========================================
// Scenario 1: Infinite Recursion
// ==========================================
/*
   The board demonstrates a recursive function failing to reach its base condition.
   Because 'int s = 5;' is an 'auto' variable, every time main() calls itself,
   a brand new stack frame is created with a fresh 's' initialized back to 5.
*/
void recursive_main() {
    int s = 5;
    printf("%d ", s);                           // Prints 5

    if (--s)                                    // s becomes 4. 4 is non-zero (true).
        recursive_main();                       // Calls main() again, allocating a NEW s=5.

    printf("%d ", s);                           // Unreachable
}
/*
   Output: 5 5 5 ........
   Result: R.T.E: Stack Overflow
*/

// ==========================================
// Scenario 2: Infinite Loop
// ==========================================
void loop_main() {
    while(1) {
        printf("hello");
    }
}
/*
   Output: hello hello hello .... ∞ times
   Result: Executes infinitely without crashing.
*/

// ==========================================
// Scenario 3: Mutual Recursion
// ==========================================
/*
   The board shows two functions calling each other in an endless cycle, labeled
   with "A <-> B Deadlock".
*/
void g();
void f() {
    g();
}
void g() {
    f();
}
/*
   Result: R.T.E: stack overflow
*/

/*
   FLOW DIAGRAM (Stack Depth Analysis)
   The whiteboard draws a series of U-shaped containers to contrast how memory
   behaves in a loop versus recursion.

   1. The Infinite Loop (Middle Board Stack Diagram)
   When printf ('P') is called inside the while(1) loop, it is pushed on top
   of main ('m'). Once printf finishes printing "hello", it is popped off
   the stack (shown by the crossed-out 'P').
   The stack depth never exceeds 2 frames. It breathes in and out indefinitely.

     |   |      |   |      |~~~|      |   |      |~~~|
     |   | ---> |   | ---> |~P~| ---> |   | ---> |~P~|
     |___|      |_m_|      |_m_|      |_m_|      |_m_|

   2. The Mutual Recursion (Right Board Flow)
   Function 'g' calls 'f', which calls 'g', pushing a new frame every time.
   The stack only grows and never pops, eventually colliding with the heap/BSS.

     | f |
     | g |
     | f |
     |_g_| ---> R.T.E: stack overflow
*/
```
