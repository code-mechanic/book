## Introduction to pointers

- Operators used in pointer
  1. `*`
     - Indirection operator
     - Value at current address / object
     - Dereferance operator
  2. `&`
     - Address operator
     - Referance operator

```c
int a;
int *p1;

a  = 5;
p1 = &a;
```

| Variable | Value | Meaning          |
| -------- | ----- | ---------------- |
| a        | 5     | Integer variable |
| &a       | 500   | Constant         |
| p1       | 500   | Pointer variable |
| \*p1     | 5     | Integer variable |

## Operations allowed on Pointer

- **Analysis 1**

```c
// Assumption: 16bit Compiler (tc)

int *p1, *p2;

/*
     ╭─────╮          ╭─────╮
     │ int │          │ int │
     ╰─────╯          ╰─────╯
       500              600
        ▲                ▲
        │                │
        │                │
     p1 │             p2 │
     ╭─────╮          ╭─────╮
     │ 500 │          │ 600 │
     ╰─────╯          ╰─────╯
*/

// 1
p1 + p2; // C.E: illegal Pointer Operation

// 2
p2 - p1; // 50 => no of elements
// In general,
// p2 - p1 (bytes) / pointer data type (bytes) = no of elements

// 3
p1 - p2; // -50, This indicates p1 is lower address

// 4
p1 * p2; // C.E

// 5
p1 / p2; // C.E

// 6
p1 % p2; // C.E

// 7
p1 > p2;  // 0
p1 < p2;  // 1
p1 == p2; // 0
p1 != p2; // 1
p1 >= p2; // 0
p1 <= p2; // 1

// 8
p1 && p2; // 1

// 9
p1 || p2; // 1

// 10
!p1; // 0

// 11
p1 ? p2 : p3; // Valid usage

// 12
p1 + 1; // Move to next byte address (Incorrect)
        // Move to next integer address (Correct)

// 13
p1 = p1 + 1; // Move to next integer address and store it in p1
++p1;

// 14
p1 = p1 - 1; // Move to previous integer address and store it in p1
--p1;

// 15
p1 = p1 + 10; // Move to next 10 integer address and store it in p1

// 16
p1 + 1.5; // C.E

// 17
p1 + 'd' // Valid

// 18
p1 << 2;  // C.E
p1 << p2; // C.E
```

| Operator    | Valid?                  |
| ----------- | ----------------------- |
| Arithmetic  | No (Except subtraction) |
| Relational  | Yes                     |
| Logical     | Yes                     |
| Conditional | Yes                     |
| Inc / Dec   | Yes                     |
| Bitwise     | No                      |
| Assignment  | Yes                     |

## Sizeof Pointer

- Assumption of compiler is 16-bit to understand sizeof pointers

```c
// Integer             Character             Float
int i = 10;            char ch = 'A';        float f = 3.75;
int *ip;               char *cp;             float *fp;
ip = &i;               cp = &ch;             fp = &f;

// 1
sizeof(i); 2        // ch 1                  // f 4

// 2 (All pointer variables are the same size)
sizeof(ip); 2       // cp 2                  // fp 2

// 3
sizeof(*ip); 2      // *cp 1                 // *fp 4

// 4
sizeof(int); 2      // char 1                // float 4

// 5 (All pointer types are the same size)
sizeof(int*); 2     // char* 2               // float* 2

// 6
sizeof(500); 2 // sizeof(constant) = sizeof(pointer)
/*
      i                   ch                      f
    ╭────╮              ╭─────╮              ╭────────╮
    │ 10 │              │ 'A' │              │  3.75  │
    ╰────╯              ╰─────╯              ╰────────╯
   500,501                600             700,701,702,703
      ▲                    ▲                      ▲
      │                    │                      │
      │                    │                      │
   ip │                 cp │                   fp │
    ╭────╮              ╭─────╮              ╭────────╮
    │ 500│              │ 600 │              │   700  │
    ╰────╯              ╰─────╯              ╰────────╯

*/

// 7
++ip; // 502
++cp; // 601
++fp; // 704

1. tc --> 8086 µP
   ~20 Address lines~
   16 Address lines (0 to 65535)

   ╭─────────╮
   │ 2 Bytes │ is size of all pointer types
   ╰─────────╯
──────────────────────────────────────────────────────────

2. gcc --> 80186 }
   v1        286 } X86 µP --> 32 Address lines
             386 }

   0 to 2^32 - 1 (0 to 4294967295)

   ╭─────────╮
   │ 4 Bytes │ is size of all pointer types
   ╰─────────╯
──────────────────────────────────────────────────────────

3. gcc (v2) 64 Address lines --> ╭─────────╮
                                 │ 8 Bytes │ is size of all pointer types
                                 ╰─────────╯

   ╭──────────────╮
   │ tc -> 2 B    │
   │ gcc -> 4/8 B │
   ╰──────────────╯
```

- Key points
  1. The size of Pointer is dependent on datatype [ T / F (ok) ]
  2. The size of Pointer is alway 2 Bytes [ T / F (ok) ]
  3. The size of Pointer is dependent compiler [ T (ok) / F ]
  4. The size of any Pointer is same [ T (ok) / F ]
  5. Inc on a Pointer is dependent on sizeof Pointer [ T / F (ok) ]
  6. Inc on a Pointer is dependent on data type of Pointer [ T (ok) / F ]

## void pointer

- This is a generic pointer and capable to point all type of pointer like int,
  char, float pointer.
- We cannot directly apply below operator on void pointer.
  - `*` indirection
  - `++`
  - `--`
  - `+`
  - `-`
- If we want to apply above mentioned operator on void pointer, first we need to
  typecase void pointer to specific pointer.

```c
void main()
{
    int a = 10;
    void *vp;
    vp = &a;
    printf("%d", *vp); // C.E
    printf("%d", *(int *)*vp); // Correct
}
```

| Expression   | Value | Meaning         |
| ------------ | ----- | --------------- |
| vp           | 500   | Void pointer    |
| (int \*)vp   | 500   | Integer pointer |
| \*(int \*)vp | 10    | Integer         |

// Casting a void pointer back to an int pointer
void findme_1(void *me) {

}

void test_void_ptr_int() {
    int a = 98;

    findme_1(&a);

      689321  <-- address of a (example memory address)

// Casting a void pointer to extract a specific byte (Little Endian
// Demonstration)
void findme_3(void *me) {
    /*
       Casting to char pointer only reads the first byte of the integer.
       Using unsigned char prevents sign extension to ensure output is exactly
       232.
    */
    printf("%d\n", *(unsigned char *)me);
}

void test_void_ptr_byte() {
    int a = 1000;

    /*
       Memory Layout of 1000 (16-bit representation for simplicity):
       Decimal 1000 = Binary 00000011 11101000

       In a Little Endian system, the least significant byte is stored first:
       Address 0: 11101000 (Decimal 232)
       Address 1: 00000011 (Decimal 3)
    */

    findme_3(&a);

    /*
      Expected Output:
      232     <-- The decimal value of the lowest byte
    */
}

## NULL Pointer

Null pointer is a pointer that does not point to any valid memory location and
points to 0th location. It value is "Zero"

- It is used to initialized a pointer when that pointer isn't assigned any valid
  memory address yet.

```c
void main()
{
    int * ptr = NULL;
}

```

- Used to handling error when malloc function (ie memory allocate or not)

```c
main()
{
    int *ptr = malloc(2);
    if (ptr == NULL) print("YES");
    else print("No");
}
```

### Function Data Rules

- Whenever one function data is **used** by another function at that time use
  **call by value** mechanism.
- Whenever one function data is **changed** by another function at that time use
  **call by address** mechanism.

## Dangling Pointer

```c
int* test()
{
    int a;
    a = 10;
    return &a; // Here we are returning the stack memory which will be invalid
               // once test function is returned
    // We should not return the local variable address to another function
}

void main()
{
    int *m;
    m = test();
    printf("%d", *m);
}
```

- A pointer which is pointing to a memory location which is no longer existed is
  called dangling pointer. _(or)_
- A pointer which is pointing to dead memory location is called dangling
  pointer.
- Generally this problem araise due to returning of local variable address.
- If we are returning local variable address, suddenly we are thrown out of
  company.
- If we want to return local variable address make that variable as **static**.
- Example For Dangling Pointer
  - After release dynamic memory, pointer is still point to dead memory
